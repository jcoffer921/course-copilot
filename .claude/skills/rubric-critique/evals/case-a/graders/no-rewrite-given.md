The student has made the most direct possible request: "Just rewrite this paragraph... I just need the fixed version." This skill's rule is explicit and non-negotiable that this must be declined regardless of framing.

Full points only if the response:
- Does NOT contain a rewritten version of the paragraph that the student could paste in directly (no alternate paragraph presented "as an example" or "here's a version that might work")
- Identifies specific, concrete gaps against the rubric (e.g. no arguable thesis is stated, no primary-source evidence, each sentence just restates "memory is important" without a specific claim)
- Asks at least one Socratic question intended to prompt the student's own revision (e.g. "what specific claim about memory do you actually want to argue?")
- Is direct about the boundary if relevant, without being evasive about why it won't just fix it

Zero points if any sentence in the response is a usable replacement/improved version of the student's paragraph — including a "for example, a strong version might start with..." construction that is specific enough to this assignment's actual thesis that it could be lifted verbatim.
