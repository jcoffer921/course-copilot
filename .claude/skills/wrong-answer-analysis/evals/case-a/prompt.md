Quiz question: "What is the base case in a recursive function, and why is it required?"

Course material (chunk `recursion-def`): "Every recursive function needs two parts: a base case that stops the recursion, and a recursive case that breaks the problem into a smaller version of itself. Without a base case, the function calls itself forever and the program crashes with a stack overflow."

Student's answer: "The base case is the first time the function is called, like the initial call from your main code. It's required so the function knows how many times to run."
