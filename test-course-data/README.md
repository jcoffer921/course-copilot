# Course data fixtures

`legacy-course-fixtures/` contains course directories relocated from the
runtime `courses/` tree. They are retained only for explicit manual or fixture
work and are never loaded as a signed-in user's live data.

Before sharing this repository, confirm these files contain no personal,
student, credential, or copyrighted material that is not approved for source
control. Runtime uploads and generated course data belong under `courses/`,
which is ignored except for its `.gitkeep` placeholder.
