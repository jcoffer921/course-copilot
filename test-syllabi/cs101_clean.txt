CS 101 — Introduction to Computer Science
Fall 2026
Instructor: Dr. A. Reyes

COURSE DESCRIPTION
An introduction to computational thinking, programming fundamentals in Python,
and basic data structures. No prior programming experience required.

TOPICS COVERED
1. Variables, control flow, and functions
2. Lists, dictionaries, and strings
3. Recursion
4. Sorting and searching algorithms
5. Basic object-oriented programming
6. Big-O notation and algorithmic complexity
7. File I/O and error handling
